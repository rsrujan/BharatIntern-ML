## 📁 Projects Overview

### 1. 🌸 Iris Flower Classification
- **Objective**: Classify iris flowers into three species (*Setosa*, *Versicolor*, *Virginica*) based on features like petal and sepal dimensions.
- **Tech Stack**: Python, Scikit-learn, Matplotlib, Pandas
- **Algorithms Used**: Logistic Regression, Decision Tree, SVM
- **Key Highlights**:
  - Data visualization for feature analysis
  - Model training and evaluation using accuracy metrics
  - Comparison of different classifiers

### 2. 🏠 House Price Prediction
- **Objective**: Predict the selling price of houses based on various features like area, number of rooms, location, etc.
- **Tech Stack**: Python, Pandas, Scikit-learn, Seaborn
- **Approach**:
  - Data preprocessing: handling null values, feature encoding
  - Feature selection and correlation analysis
  - Linear Regression model for prediction
- **Outcome**:
  - Trained model to predict house prices with minimal error

### 3. 🎬 Movie Recommendation System
- **Objective**: Recommend similar movies based on user input using content-based filtering.
- **Tech Stack**: Python, Pandas, Scikit-learn (TF-IDF), Cosine Similarity
- **Key Features**:
  - Text vectorization using TF-IDF
  - Cosine similarity-based recommendation
  - Returns top N movies similar to a given title
